# NLP Paper Notes

NLP 논문을 한 편씩 읽고, 이해한 내용을 내 말로 설명하고, 작은 연구 질문으로 연결하는 기록입니다.

다른 인공지능 분야의 석사 수준 배경에서 NLP 연구를 이해하는 것을 목표로 합니다. 논문별 정리에는 **문제 → 방법 → 실험 근거 → 내 해석 → 후속 실험**을 남깁니다.

첫 범위는 [서울대학교 MILAB](https://milab.snu.ac.kr/)의 Kyomin Jung 교수 연구 중 **2022~2026년 대화·요약·질의응답 관련 논문**입니다. 2026-10-23까지 공개된 자료를 기준으로 했으며, 중요한 선행논문은 발표 연도와 소속에 관계없이 연결합니다. [선별 읽기 목록과 순서](reading-list.md)에서 다음 논문을 고를 수 있습니다.

학습 자료가 작성되었다는 것은 사용자가 원문 정독이나 재현을 완료했다는 뜻이 아닙니다. 읽기·구현 상태는 실제 수행 후 갱신합니다.

## 새 논문을 추가하는 방법

1. `papers/YYYY-short-title/` 폴더를 만듭니다. 연도는 논문 발표 연도, 이름은 짧은 영문 소문자와 하이픈으로 통일합니다.
2. [논문 정리 템플릿](templates/paper-note.md)을 복사해 해당 폴더의 `README.md`로 저장합니다.
3. 우선 핵심 요약, 문제, 방법, 주요 결과와 남은 질문을 채웁니다. 깊게 읽을 논문은 수식 설명과 구현 기록을 보강합니다.
4. 깊게 공부할 논문에는 `easy-explanation.md`, `detailed-explanation.md`, `quiz.md`, `references.md`를 추가하고 논문 README에서 연결합니다. 설명에 필요한 그림은 해당 논문의 `figures/`에 두고 출처와 원문 번호를 적습니다.
5. 위 논문 목록에 정리 링크를 추가합니다. 여러 논문에서 연결되는 질문은 [연구 아이디어](research-ideas.md)에 모읍니다.
6. 내용을 검토한 뒤 커밋하고 기본 브랜치인 `main`에 푸시합니다.

예를 들어 폴더 이름이 `2025-example-paper`라면 정리 파일은 `papers/2025-example-paper/README.md`입니다. 이 이름은 설명용이며 실제 논문을 뜻하지 않습니다.

```text
│       ├── original.pdf               # ACL 공식 출판본, 원문 그대로
│       ├── easy-explanation.md        # 쉬운 설명과 구체적 예시
│       ├── detailed-explanation.md    # 수식 · 방법 · 실험 해설
│       ├── quiz.md                    # 문제와 접힌 정답·해설
│       └── references.md              # 핵심 참고논문과 연결 이유
├── reading-list.md                    # 최근 5개년 선별 목록과 읽기 경로

```

## 기록 원칙

- **논문 내용과 내 생각을 구분합니다.** 저자의 주장, 실험으로 확인한 결과, 개인적인 해석을 각각 표시합니다.
- 핵심 주장·수치·수식에는 `§3.2`, `Table 2`, `Eq. (4)`처럼 원문의 근거 위치를 남깁니다.
- NLP 개념은 정의와 함께 작은 입력·출력 예시로 설명합니다. 반복되는 배경 설명이 많아지면 나중에 별도 문서로 모읍니다.
- 결과를 비교할 때 데이터 분할, 지표, 모델 크기, 평가 조건을 함께 적습니다. 조건이 다른 점수는 직접적인 우열 비교에 사용하지 않습니다.
- AI가 만든 설명은 초안으로 활용합니다. 원문에서 확인하지 못한 부분은 `미확인`으로 남기고, 실제로 수행하지 않은 실험이나 개인 의견을 채워 넣지 않습니다.
- 논문 원문과 공식 코드에는 링크를 남깁니다. 저장소에는 직접 작성한 설명과 필요한 자료를 중심으로 기록합니다.

## 상태 표시

| 구분 | 값 | 의미 |
| --- | --- | --- |
| 읽기 | 미시작 | 학습 자료만 준비되었으며 아직 읽지 않음 |
| 읽기 | 훑어봄 | 초록·서론·결론 등을 중심으로 주제와 기여를 파악함 |
| 읽기 | 정독 중 | 방법과 실험을 확인하며 질문을 정리하는 중 |
| 읽기 | 정독 완료 | 본문을 읽고 핵심 방법·결과·한계를 정리함. 남은 질문은 별도로 기록 |
| 구현·재현 | 미시도 / 진행 중 / 완료 | 코드 실행·구현 여부. 완료 시 실제로 확인한 실험 범위와 결과를 기록 |

## 연구 방향

개별 논문에서 얻은 아이디어를 [research-ideas.md](research-ideas.md)에서 비교합니다. **연구 질문 → 가설 → 기준 모델 → 변경할 요소 하나 → 평가 방법**이 연결되는지 확인하고, 3개월 안에 수행할 수 있는 최소 실험부터 구체화합니다.

## 첫 논문 공부 순서

1. [IterCQR 학습 안내와 공식 원문](papers/2024-itercqr/README.md)에서 초록과 Figure 1을 훑습니다.
2. [쉬운 설명](papers/2024-itercqr/easy-explanation.md)으로 문제와 전체 흐름을 잡습니다.
3. 원문 Figure 2·Algorithm 1·Table 1과 [상세 설명](papers/2024-itercqr/detailed-explanation.md)을 함께 읽습니다.
4. [퀴즈](papers/2024-itercqr/quiz.md)를 정답을 펼치지 않고 풀고, 설명이 막힌 부분으로 돌아갑니다.
5. [핵심 참고논문 노트](papers/2024-itercqr/references.md)에서 CONQRR·ConvGQR·MBR의 연결을 확인합니다. 다른 논문의 완전한 정독 자료는 이후 한 편씩 추가합니다.
