# 논문별 정리

논문 하나당 `YYYY-short-title/` 폴더를 만들고, [논문 정리 템플릿](../templates/paper-note.md)을 복사한 `README.md`를 넣습니다.

```text
YYYY-short-title/
├── README.md                  # 공식 원문 링크와 템플릿 정리
├── easy-explanation.md        # 쉬운 설명: 깊게 공부할 때 추가
├── detailed-explanation.md    # 상세 설명: 깊게 공부할 때 추가
├── quiz.md                    # 문제와 접힌 정답·해설
├── references.md              # 핵심 참고논문 노트와 후속 읽기
└── figures/                   # 그림이 필요할 때 생성
```

- 원문 링크, 공식 코드, 발표 정보와 읽은 원문 버전을 먼저 기록합니다.
- 처음에는 요약·문제·방법·주요 결과·남은 질문부터 작성합니다.
- 그림은 개별 논문의 `figures/`에 넣고 `![설명](figures/파일명.png)`처럼 상대 경로로 연결합니다.
- 본문에서 참고 문헌이나 다른 정리를 언급할 때 링크를 남깁니다.
- 정리를 추가하면 [전체 논문 목록](../README.md)도 갱신합니다.
- 자료 작성 상태와 사용자의 실제 읽기·구현 상태를 구분합니다.

권장 순서는 **원문 훑기 → 쉬운 설명 → 원문과 상세 설명 → 퀴즈 → 핵심 참고논문**입니다. 설명을 읽은 뒤에는 원문을 보지 않고 입력·출력, 학습 목적, 핵심 실험과 한계를 설명해 봅니다.
